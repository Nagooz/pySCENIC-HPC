# pySCENIC-HPC: Adaptation of PySCENIC for HPC with Nextflow

## Description
This repository contains an adaptation of the `pySCENIC` code for execution **on an HPC cluster without using Docker or Singularity**. The project is configured to be run via Nextflow to manage the execution of different steps in the analysis. The goal is to enable the execution of pySCENIC on large-scale computing resources while remaining compatible with containerless systems.

## Prerequisites
+ Nextflow installed on your machine or HPC system
+ A Python environment set up via Miniconda or Anaconda (see `requirements.txt`)
+ Access to an HPC cluster with the necessary resources to run the analyses

## Directory Structure
Here is an overview of the project structure and what each directory contains:

### `data/`
This directory contains the data files needed to run pySCENIC:

+ `allTFs_mm.txt` : List of transcription factors
+ `ASC.h5ad` : Single-cell data in `Anndata` format
+ `ASC_scenic_count.loom` : Single-cell data in `loom` format
+ `motifs-v9-nr.mgi-m0.001-o0.0.tbl` : Regulatory motifs table
+ `*.feather` : Scores of regulatory motifs 

### `env/`
This directory contains the files needed to set up the Python environment and dependencies:

+ `requirements.txt` : List of required Python dependencies

### `modules/`
The modules contain scripts and notebooks for executing different parts of the pySCENIC pipeline:

+ `download_aux_datasets.sh` : Script to download auxiliary datasets for the analysis (`allTFs_mm.txt`, `motifs-v9-nr.mgi-m0.001-o0.0.tbl`, `*.feather`)
+ `Seurat_to_Anndata.Rmd`, `Anndata_loom_file.ipynb` : Notebooks to convert Seurat objects into Anndata objects and loom format
+ `install_miniconda.sh`, `install_python.sh` : Script to install Python v3.10 and Miniconda
+ `environment_setup.sh` : Script to set up the working environment
+ `scenic_aucell.sh`, `scenic_ctx.sh`, `scenic_grn.sh` : Scripts to execute different steps of the analysis (AUCELL, SCENIC, GRN)

### `scripts/`
The scripts needed to run the pipeline with Nextflow and submit tasks to the HPC cluster:

+ `nextflow.config` : Configuration file for Nextflow, specifying the resources to use for each pipeline step
+ `pyscenic_pipeline.nf` : Main Nextflow pipeline that orchestrates the execution of the steps
+ `submit_pyscenic_pipeline.sh` : Script to submit the Nextflow pipeline to the HPC cluster

### `results/`
This directory contains the results generated by the pySCENIC pipeline:

+ `.loom` and `.csv` files generated after analysis with pySCENIC

## Installation
1. Clone the repository:
```bash
git clone https://github.com/Nagooz/pySCENIC-HPC.git
cd pySCENIC-HPC
```
2. Install Miniconda (if necessary): If you do not have Miniconda, run the script to install it:
```bash
./modules/install_miniconda.sh
```
3. Set up the environment: You can create a Conda environment and install the necessary dependencies using the `requirements.txt` file:
```bash
./modules/environment_setup.sh
```
4. Configure Nextflow: Ensure you have Nextflow installed on your machine or HPC environment:
```bash
curl -s https://get.nextflow.io | bash
```

## Usage
1. Configure HPC resources (optional): If necessary, adjust the `nextflow.config` file to configure the resources (memory, CPU, etc.) for each pipeline step.

2. Run the Nextflow pipeline: Once the environment is set up, you can run the pipeline with Nextflow using the following command :
```bash
nextflow run pyscenic_pipeline.nf -c nextflow.config
```
If you need to submit the pipeline to an HPC job scheduler system, you can use the submission script :
```bash
./scripts/submit_pyscenic_pipeline.sh
```
4. Results: The results will be stored in the `results/` directory as `.loom` and `.csv` files.

## Example Pipeline
Here is an example of running a step with Nextflow on an HPC cluster :
```bash
sbatch submit_pyscenic_pipeline.sh
```
